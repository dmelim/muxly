# Skills

Agent Skills for working with Muxly. These are model/agent-agnostic — they work
with any [Agent Skills](https://docs.claude.com/en/docs/claude-code/skills)-compatible
tool (Claude Code, Codex, etc.).

| Skill | What it does |
|-------|--------------|
| [muxly-register-service](muxly-register-service/) | Register a local project as a Muxly service: discover its run command, locate `services.json`, and safely append an entry. |

See each skill's `README.md` for how to install it into your agent's skills
directory.
